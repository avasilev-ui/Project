# Трекер калорий

Личное веб-приложение под телефон для похудения. На главном экране — **сколько килокалорий дефицита осталось до целевого веса**, а не только «сколько можно съесть сегодня».

## Для кого

Пока это **личный инструмент**: вы сами вводите вес, еду, минуты быстрой ходьбы и тренировки. Без FatSecret, Apple Health и без ИИ.

## Первая версия (план)

- BMR и TDEE (формула Mifflin–St Jeor)
- Дефицит за день и за неделю; сравнение с вашим целевым дефицитом
- Главная шкала: остаток ккал до цели
- Прогноз — **диапазон дат**, не одна дата
- Прогресс по нормам ВОЗ
- Честные предупреждения: это оценки, не лабораторные измерения
