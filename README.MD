# Трекер калорий (Burn)

Личное веб-приложение под телефон для похудения. На главном экране — **сколько килокалорий дефицита осталось до целевого веса**, а не только «сколько можно съесть сегодня».

## Для кого

Пока это **личный инструмент**: вы сами вводите вес, еду, минуты быстрой ходьбы и тренировки. Без FatSecret, Apple Health и без ИИ.

## Первая версия (план)

- BMR и TDEE (формула Mifflin–St Jeor)
- Дефицит за день и за неделю; сравнение с вашим целевым дефицитом
- Главная шкала: остаток ккал до цели
- Прогноз — **диапазон дат**, не одна дата
- Прогресс по нормам ВОЗ
- Честные предупреждения: это оценки, не лабораторные измерения

## Статус

**Скелет кода создан:** формулы и тесты, хранение в браузере (IndexedDB), заглушки экранов без дизайна. Визуал и ввод данных — следующий этап.

Стек: [`docs/stack.md`](./docs/stack.md). Спецификация: [`docs/product-spec.md`](./docs/product-spec.md).

### Запуск на компьютере

Нужен [Node.js](https://nodejs.org/) (версия 20 или новее) и команда `make` (на Mac обычно уже есть).

В терминале, в папке проекта:

```bash
make setup    # один раз — установка
make start    # запуск; в терминале появятся ссылки на все экраны
make stop     # остановка
```

Справка по командам: `make` или `make help`.

Backend в первой версии **нет** — только приложение в браузере (frontend).

Проверка расчётов:

```bash
npm run test
```

Сборка для публикации:

```bash
npm run build
```
